## Setup

### Ports 

They must be free: 3000, 3001, 8081, 8091, 8092 and 8093

### Hosts file

/etc/hosts

```
127.0.0.1  plant-server cell-controller conveyor-belt-edge-gateway robotic-arm-edge-gateway monitoring-server
```

### Monitoring

- BaSyx AAS Web UI: <http://monitoring-server:3000>
- Grafana: <http://monitoring-server:3001>
